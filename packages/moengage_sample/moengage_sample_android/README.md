# moengage_sample_android

Android implementation of the [`moengage_sample`](../moengage_sample) plugin.

Note: This is a reference/scaffold module, not intended for production use.

## Usage

This package is [endorsed](https://flutter.dev/to/endorsed-federated-plugin),
so you can simply use `moengage_sample` normally. This package will be
automatically included in your app when you depend on `moengage_sample`.
